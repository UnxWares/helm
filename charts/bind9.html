Changes in 2026.11.2

From the chart's artifacthub.io/changes. This release contains security updates.

  • Security named runs as the bind user (uid 53) from the start, without any capability: the net.ipv4.ip_unprivileged_port_start sysctl lets it bind port 53 in the pod. The pods meet the restricted Pod Security Standard.
  • Security The metrics and rndc ports move from the DNS Service to their own Service, <fullname>-admin (ClusterIP by default): a LoadBalancer or NodePort DNS Service no longer publishes them.
  • Security Default exporter image moves to ghcr.io/unxwares/bind-exporter (imageProvider: unxwares): bind_exporter master built from its sources with Go 1.27 and current golang.org/x modules (proposed upstream in prometheus-community/bind_exporter#301), on a distroless base. imageProvider: upstream keeps the Prometheus community image.
  • Fixed nodeSelector defaults to kubernetes.io/arch: amd64, the only architecture of the ISC image, for the pods and the helm test pod (no more exec format error on arm64 nodes).
  • Fixed The NOTES show the image actually deployed, digest included; autoscaling.targetMemoryUtilizationPercentage is a documented value; the helm test pod uses imagePullSecrets.
  • Added End-to-end test in CI, in a namespace that enforces the restricted Pod Security Standard: the zones answer their records over UDP and TCP from another pod, transfers and other zones are refused, the exporter reports bind_up 1, and the NetworkPolicy keeps the metrics from other pods.
