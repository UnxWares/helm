openeverest-database-tools

Jobs that wait for an OpenEverest DatabaseCluster to be ready, then create PostgreSQL, MySQL and MongoDB databases, users, grants and run init scripts.

Install

With the signature check: see Verify for the key.

helm repo add unxwares https://helm.unxwares.studio
helm install openeverest-database-tools unxwares/openeverest-database-tools --version 2026.11.3 \
  --namespace openeverest-database-tools --create-namespace \
  --verify --keyring ~/.gnupg/unxwares-helm.gpg

The suites

End to end

Passed

15 checks, all passed.

Checks of the end-to-end scripts, in order. Each check ran twice in the job.

  • PostgreSQL: laravel-app logs in over TLS
  • PostgreSQL: laravel-app owns its database
  • PostgreSQL: init script created the pg_trgm extension
  • PostgreSQL: laravel-app writes to the table of an init script
  • PostgreSQL: laravel-app creates tables in its database
  • PostgreSQL: laravel-app cannot create tables in another database
  • MySQL: wordpress logs in
  • MySQL: the session is encrypted
  • MySQL: wordpress has the configured privileges on wordpress.*
  • MySQL: wordpress has no global privilege
  • MySQL: wordpress writes to the table of an init script
  • MySQL: wordpress cannot read the system tables
  • MongoDB: appdb logs in and writes to its database
  • MongoDB: init script created the unique index
  • MongoDB: appdb cannot read another database
Steps of the job
  • Checkout
  • Build the client images
  • Create kind cluster
  • Load the client images
  • Install Helm
  • Start PostgreSQL, MySQL, MongoDB and the DatabaseClusters
  • Install the chart and run its Jobs
  • Check the databases, users and grants
  • Rotate the application passwords
  • Run the Jobs again
  • Check again with the new passwords
  • Diagnostics (skipped)
