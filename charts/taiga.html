CVE watch of 2 Nov 2026, 15:33 UTC · run · issue

Changes in 2026.11.2

From the chart's artifacthub.io/changes.

  • Fixed Periodic tasks were sent once per async worker (each ran its own Celery beat): the beat scheduler now runs once, in its own async-beat Deployment (one replica, Recreate strategy), so the workers can be scaled.
  • Changed async.command defaults to the Celery worker without beat; a command that starts a beat scheduler (docker/async_entrypoint.sh, -B) is refused. New async.extraArgs for Celery options such as --concurrency.
  • Fixed The chart Secret is kept on uninstall (helm.sh/resource-policy: keep), like the database and media claims, so a reinstall keeps the passwords the volumes were initialized with.
  • Fixed taiga-events connects to eventsRabbitmq.service.port instead of always 5672.
  • Fixed The async pods also use backend.imagePullSecrets (they run the backend image).
  • Fixed events and protected restart when the chart Secret changes.
  • Fixed Value descriptions corrected: global resources and security contexts, OIDC endpoints (no discovery), external database with an existing Secret, events broker vhost, sub-path.
  • Added Optional NetworkPolicies (networkPolicy.enabled): the gateway is the only entry point, the database and the brokers only accept the components that use them.
  • Added helm test through the gateway: API, front and its configuration, static files, events websocket handshake, refusal of an unsigned attachment URL. It creates nothing.
