Changes in 2026.11.2

From the chart's artifacthub.io/changes. This release contains security updates.

  • Security backend.trustProxy defaults to "1", the chart's own frontend nginx: behind an Ingress or a Gateway that terminates TLS, session and CSRF cookies now get the Secure flag. See Upgrading in the README.
  • Changed The backend runs with a read-only root filesystem: an init container copies /app/dist into an emptyDir, which also holds /app/uploads.
  • Fixed The chart Secret is kept on uninstall (helm.sh/resource-policy: keep), like the PVC: a new install keeps sessions and API keys valid.
  • Fixed The OIDC modes require backend.auth.oidc.clientId as well as issuerUrl, and an https:// redirect URI in production, without which the backend does not start.
  • Fixed helm test uses the image pull secrets and pull policy of the frontend, and sets resources.
  • Added frontend.autoscaling.targetMemoryUtilizationPercentage, already read by the HPA template.
  • Fixed NOTES explain how the first administrator is created in each authentication mode.
  • Added End-to-end test in CI: onboarding with the setup code, login, drawing created, listed, exported and accepted by the import check, Secure cookies behind TLS, NetworkPolicy, then what a new install keeps.
