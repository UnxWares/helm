Install

With the signature check: see Verify for the key.

  --namespace kener --create-namespace \

Changes in 2026.11.3

From the chart's artifacthub.io/changes.

  • Fixed The chart Secret is kept on uninstall (helm.sh/resource-policy: keep), like the SQLite PVC: a new install reads the generated KENER_SECRET_KEY back, so sessions and API keys keep working.
  • Fixed podDisruptionBudget.enabled is refused with SQLite, and when minAvailable is not lower than the number of replicas: such a budget blocked node drains.
  • Fixed An empty redis.image.tag no longer falls back to a Valkey tag hidden in the templates: the chart asks for a tag or a digest.
  • Added proxy.existingSecret (keys existingSecretHttpProxyKey and existingSecretHttpsProxyKey) reads HTTP_PROXY and HTTPS_PROXY from your own Secret.
  • Added End-to-end test in CI: first account and login, API key, monitor created through the REST API and run from the queue, status page and badge, Valkey password and NetworkPolicies, then what a new install keeps.
